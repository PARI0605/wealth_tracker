Academic Viva Defense: Applied AI/ML Architecture

This project integrates three distinct foundational Machine Learning paradigms to fulfill college minor project requirements:

1. Naive Bayes Classification (NLP):

Uses Bayes' theorem $P(C|D) \propto P(C)\prod P(w_i|C)$ with Bag of Words (bi-grams) for fast text classification with cold-start fallback.

2. Time-Series Linear Regression:

Calculates slope $\beta_1 = \frac{\sum (x-\bar{x})(y-\bar{y})}{\sum (x-\bar{x})^2}$ to project next month's spending burn rate based on historic velocity.

3. Anomaly Outlier Detection:

Combines category-scoped Z-score deviations ($Z = \frac{x - \mu}{\sigma} > 2.0$) with Isolation Forest tree partitioning to isolate abnormal expenditures.
